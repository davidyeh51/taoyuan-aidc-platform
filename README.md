## 內容架構
- **Part 1 選址建議 (5 頁)**
  - 1.1 台灣 AIDC 選址核心邏輯與五大支柱在地化重排
  - 1.2 併網硬約束與 2 公里法則（大潭/協和 2km、名義申請作廢率 70%）
  - 1.3 土地分區與環境防護（丁種建地高容積 ＋ 水保滯洪池綜效）
  - 1.4 電信網路、海纜登陸與超低延遲拓撲（Sub-1ms 樞紐）
  - 1.5 30 分鐘場址初評清單與 Go / Hold / Stop 決策表
- **Part 2 個案背景：桃園 40MW 實戰開發 (7 頁)**
  - 2.1 地籍分區與案場總體規劃（4,321 坪丁工 ＋ 4,657 坪水保滯洪）
  - 2.2 4 層鋼構建築剖面（樓板承重 2.5 T/m² ｜ 白區灰區分離 ｜ PUE < 1.15）
  - 2.3 480Vac→800Vdc 集中整流架構與 Vera Rubin Ready 路徑（巴拿馬成熟方案 ｜ 電流降 94%）
  - 2.4 戰略電信中立樞紐與北台灣黃金三角網路（淡水海纜 / 台北金融 / 竹科半導體）
  - 2.5 非約束性意向書 (LOI) 核心指標與 15 年 NNN 包租條款（USD 180~210 / kW / Mo）
  - 2.6 台電 161kV 併聯與變電所節點研討（南崁 D/S 5km / 長安 D/S 7km）
  - 2.7 協力廠商與顧問團隊（台灣字節橋 / 佰橋科技）
- **Part 3 商模、資金與里程碑 (3 頁)**
  - 3.1 三類營運模式比較、分拆彈性 (10MW×4) 與資產退出策略（白區租賃 vs 整機買斷 vs JV）
  - 3.2 資金結構與機構對接：壽險資管 (富邦/國泰) ＋ 專案融資雙軌（自有資金 5~10%）
  - 3.3 專案推進里程碑、9 月美商 Colo 招商與 Gate 1~3 閉環
